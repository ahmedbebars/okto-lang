The mistake is caught before the program runs.
And the fix comes with it.

Okto is a small, strict programming language with English and Arabic keywords. It compiles to JavaScript and to one native program, and it has safety rules built in.

Try it in the browser Install

Whole families of bugs, removed by the language

No none surprises

Only a type marked ? can hold none, and it cannot be used until it is checked.

No hidden changes

Lists, dicts and records are copied on assignment. Two names never share one value.

Errors that teach

Every error has a code, a message and a fix: line, in English or Arabic, and as JSON for tools.

Permissions

A program touches files and environment values only if it says so with allow.

Secrets stay secret

A secret cannot be printed, logged or written, and is compared in constant time.

No SQL injection

A query is its own type. Values travel apart from the query text.

Two backends, one output

Run on Node while you write. Ship one native program built with Go. Every test runs on both.

Made for AI assistants

The whole language fits in one guide, with one way to do each thing and errors a machine can act on.

Playground

The real compiler, running in your browser. Nothing is sent to a server.

Files, environment values and secrets need a computer: install Okto to try them. Indent with 4 spaces (the Tab key does it). Ctrl + Enter runs.

Install

Python 3.10 or newer, and Node.js 22 or newer to run programs. Go 1.26 or newer to build native programs.

pip install git+https://github.com/ahmedbebars/okto-lang
okto run hello.ok
okto build hello.ok

Or download okto.pyz from the latest release and run python okto.pyz.
